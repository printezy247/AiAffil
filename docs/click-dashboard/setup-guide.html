Click Dashboard

Feature 10 of 13 — see which tools are actually getting clicked, password-protected.

One password to set Also tracks email subscribers Free Upstash tier recommended

1What this does

Every "Visit" click across the whole site (tools, brokers) now increments a counter. A private dashboard at /admin/links shows every tool sorted by click count, plus your email subscriber list underneath — one password-gated page for both.

2Turn it on

  1. Set ADMIN_DASHBOARD_PASSWORD to anything you want (e.g. a random passphrase) as an environment variable.
  2. Redeploy (env var changes need a redeploy to take effect — this page is built to always check fresh, but the variable itself has to be present at deploy time).
  3. Visit yourdomain.com/admin/links and log in with that password.
Set up persistent storage or counts will reset Without UPSTASH_REDIS_REST_URL / UPSTASH_REDIS_REST_TOKEN (free tier at console.upstash.com), click counts and subscriber emails are stored in a local file that most hosting providers wipe on every redeploy. The dashboard shows a visible warning banner whenever this isn't configured, so you'll always know which mode you're in.

3Security note

This uses a simple shared-password cookie, not a hashed session or user accounts — appropriate for a low-stakes internal dashboard (click counts, email addresses you already collected) on a small personal site. Don't reuse this exact pattern for anything handling payment info or other sensitive data.
