Telegram Mini App

Feature 3 of 13 — your full tool catalog, opening inside Telegram itself.

No app store No extra hosting Matches user's theme automatically

1What this does

A Mini App is a normal web page that opens inside Telegram's own interface — no browser tab, no app install. Your catalog now has a version at /telegram built specifically for this: it detects Telegram's theme (light/dark/custom) and repaints itself to match, shows a personalized "Hey, [name]" greeting, and every tool tap opens correctly through Telegram's own link handler.

It uses no different data — same data/products.json catalog as the website and the daily bot post.

2Deploy first

Telegram requires HTTPS Mini Apps only work over a real public HTTPS URL — Telegram will not load localhost. Deploy the site (see the main README's "Put it online for free" section) before doing the steps below. You'll need your live URL, e.g. https://yourdomain.com.

3Register it with BotFather

Uses the same bot you already created for the daily poster (feature 1). Two ways to attach a Mini App to it — pick one:

OPTION A — SIMPLEST
Menu Button
Message @BotFather → /mybots → select your bot → Bot Settings → Menu Button → Configure Menu Button → paste https://yourdomain.com/telegram and a label like "Open App".
OPTION B — SHAREABLE
/newapp
Message @BotFather → /newapp → follow the prompts (short name, title, description, icon, then the same /telegram URL). This gives you a shareable link like t.me/yourbot/appname.
EITHER WAY
Test it
Open a chat with your own bot in Telegram (mobile app works best) and tap the menu button / app link. Your catalog should open inside Telegram, themed to match your Telegram app.

4How the theming works (for reference, no setup needed)

Telegram passes theme colors and user info to the page automatically once it loads — no configuration required. The relevant code:

FilePurpose
app/telegram/page.tsxThe Mini App route
components/TelegramMiniApp.tsxThe catalog UI shown inside Telegram
components/TelegramWebApp.tsxLoads Telegram's SDK, reads theme colors and user info
components/SiteChrome.tsxHides the normal website nav/footer on this one route
Previewing without Telegram Visiting yourdomain.com/telegram in a normal desktop browser still works — it just falls back to light/dark based on your system theme, with no personalized greeting, since there's no real Telegram client to read data from.

5Customizing it

  • Change what's shown: edit components/TelegramMiniApp.tsx — it's a normal React component.
  • Change the icon/name Telegram shows: re-run /newapp's settings via BotFather → /myapps.
  • Add a native-feeling action button: Telegram's SDK has a MainButton API (not wired up yet) — ask to have it added if you want e.g. a persistent "Suggest a Tool" button.

6Troubleshooting

ProblemFix
Menu button does nothingDouble-check the URL you gave BotFather is your real deployed HTTPS domain, not localhost
Opens but looks like a plain website (nav/footer visible)Make sure you're opening /telegram, not the homepage /
Colors look wrongTelegram itself controls these via the user's chosen theme — try switching your own Telegram app's theme to see it update
Tapping a tool does nothingUpdate to the latest Telegram app version — older clients may not support openLink
