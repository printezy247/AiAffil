Broken-Link Checker

Feature 11 of 13 — catches dead affiliate links automatically, once a week, for free.

No setup required Free weekly GitHub Action Runs manually any time

1What this does

A script checks every URL in data/products.json and data/brokers.json — 173 links today — and reports any that are dead (404, timeout, DNS failure, etc.). It's already scheduled to run automatically every Monday via GitHub Actions, completely free.

2Nothing to configure

This is live the moment the repo is pushed to GitHub — no secrets, no environment variables. You'll see it listed in your repo's Actions tab as "Weekly broken link check."

3Run it manually any time

FROM YOUR COMPUTER
Command line
node scripts/check-links.mjs
FROM GITHUB
Actions tab
Go to Actions → "Weekly broken link check" → Run workflow
WHEN IT FAILS
What you'll see
A red ✕ in the Actions tab and a list of exactly which tools/URLs are broken in the run's log

4Fixing what it finds

Open data/products.json or data/brokers.json, find the flagged entry by name, and either fix the URL or remove the entry if the tool has shut down.

5Where the code lives

FilePurpose
scripts/check-links.mjsThe checker itself
.github/workflows/check-links.ymlThe free weekly scheduler
False positives Some sites block automated HEAD/GET requests entirely (bot protection) even though the page works fine for a real visitor. If a flagged link opens fine in your browser, it's a false positive — no action needed.
