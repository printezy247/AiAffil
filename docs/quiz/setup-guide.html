"Which AI Tool Is Right For You?" Quiz

Feature 8 of 13 — a 2-question tool finder, live at /quiz.

Zero configuration No signup required Fully client-side

1What this does

Visitors answer two questions — their main goal, then their budget preference — and get up to 3 recommended tools, featured tools prioritized. It's live and working with no setup required.

2How the matching works

Each goal ("Grow a YouTube/social video channel," "Write blogs, posts, or copy faster," etc.) maps to one category in your catalog. If the visitor picks "Free tools only," results are filtered to tools without an affiliate link; otherwise all matching tools are shown, featured ones first.

3Customizing

  • Add or change goals: edit the GOAL_TO_CATEGORY map at the top of components/Quiz.tsx — each key is a goal label shown to the visitor, each value must exactly match a category name in data/products.json.
  • Add a third question: the component holds simple local state per question — follow the existing pattern (see how budget is handled) to add another filter step.
  • Change how many results show: edit the .slice(0, 3) at the bottom of the filtering logic in components/Quiz.tsx.
