Trading Calculators

Feature 6 of 13 — position size and compound interest calculators, both live already.

Zero configuration Runs entirely in the browser No API keys

1What this does

Two interactive calculators, both already deployed and working with no setup:

PageWhat it calculates
/tools/position-size-calculatorHow many units to buy given account size, risk % per trade, entry price, and stop-loss price
/tools/compound-interest-calculatorProjected growth of a starting amount plus monthly contributions at a given return rate

Both live under a /tools index page, linked in the site nav as "Calculators," and both end in a call-to-action linking to your /brokers comparison page — turning a useful free tool into a lead into a paid signup.

2Nothing to configure

These work immediately after deploying All math runs client-side in the visitor's browser — no server calls, no API keys, no environment variables. There's nothing to set up.

3Customizing

  • Change the CTA destination: edit the "Ready to place the trade?" link in app/tools/position-size-calculator/page.tsx or app/tools/compound-interest-calculator/page.tsx — point it at a specific broker's /go/[slug] link instead of the general /brokers page if you want to push one platform.
  • Add another calculator: the shared input/result styling lives in components/calculators/shared.tsx — copy the pattern in PositionSizeCalculator.tsx for a new one (e.g. a leverage or DCA calculator).
