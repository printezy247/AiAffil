AI-Written Tool Review Pages

Feature 12 of 13 — long-form reviews for SEO and buyer confidence, 5 written already, 160 more ready to generate.

5 reviews included Scale to the rest with your own API key Never overwrites existing reviews

1What this does

Five tools (Syllaby, Go High Level, Replit, Canva, Notion) already have an in-depth, balanced review — what the tool does, one genuine strength, one honest limitation, and a "best for" verdict — displayed on their tool page. A script scales this pattern to any other tool in your catalog using your own Anthropic API key.

Written honestly, on purpose These reviews explicitly avoid inventing pricing, statistics, or competitor comparisons the tool's own description doesn't support. That's a deliberate constraint in the generation prompt — the goal is genuine buyer-helpful content, not hype copy that could damage trust if it turns out to be wrong.

2Generate more reviews

  1. Get an API key at console.anthropic.com (pay-as-you-go, no subscription).
  2. Set ANTHROPIC_API_KEY in your environment.
  3. Generate specific tools: node scripts/generate-reviews.mjs syllaby canva notion
  4. Or generate all 160 remaining at once: node scripts/generate-reviews.mjs --all
Cost awareness Each review is one API call to Claude Opus 5. Generating all 160 remaining tools at once will cost real money (a few dollars, not huge, but not free) — check console.anthropic.com for current pricing before running --all. Running it for specific tools a few at a time costs proportionally less and lets you review quality before scaling up.

3How it avoids duplicate work

The script checks data/reviews.json before generating anything — a tool that already has a review (including the 5 written by hand) is always skipped, so you can re-run --all safely as you add new tools to the catalog without wasting API calls regenerating what's already there.

4Editing a review

Every review is plain text in data/reviews.json, keyed by tool slug. Edit the title or body field directly — paragraphs are separated by a blank line in the JSON string.
