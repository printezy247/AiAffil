Live Crypto Price Ticker

Feature 7 of 13 — live prices for 7 major coins, no API key required.

No API key Free forever (CoinGecko public API) Auto-refreshes every 60s

1What this does

A new page at /markets shows live USD prices and 24-hour change for Bitcoin, Ethereum, Solana, BNB, XRP, Dogecoin, and Cardano. It fetches from CoinGecko's free public API directly in the visitor's browser and refreshes automatically every 60 seconds. Nothing to configure — it works the moment the site is deployed.

Note on testing This was built and verified against CoinGecko's documented, stable public API format. The sandbox this was built in has restricted network access, so the live fetch itself couldn't be tested end-to-end from here — confirm it's showing real numbers once your site is deployed (it should, immediately). If it ever shows "temporarily unavailable," that's the built-in graceful fallback working correctly, not a bug — CoinGecko's free tier has a modest rate limit under heavy traffic.

2Customizing

  • Change which coins show: edit the COINS list at the top of components/PriceTicker.tsx — use any CoinGecko coin ID (find them at coingecko.com, in a coin's URL).
  • Change the refresh rate: edit REFRESH_MS in the same file. Keep it at 60 seconds or higher to stay well within CoinGecko's free rate limit.
  • Add stocks instead of crypto: would need a different API (CoinGecko is crypto-only) — ask if you want this added; most stock APIs require a free API key.
