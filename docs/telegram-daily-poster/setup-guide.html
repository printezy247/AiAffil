Telegram Daily Tool Poster

Feature 1 & 2 of 13 — automated daily posts to your Telegram channel with click-tracked buttons.

No server required Free (GitHub Actions) Click tracking included

1What this does

A script picks one tool from your catalog every day — deterministically, so it rotates through your whole list before repeating — and posts it to your Telegram channel with a "Visit" button. That button routes through your site's /go/[slug] link, the same click-tracked redirect the website itself uses, so Telegram clicks show up alongside website clicks.

It runs automatically, once a day, on GitHub's own servers — you don't need to keep a computer or server running.

2Create your Telegram bot

STEP 1
Message BotFather
Open Telegram, search for @BotFather, and start a chat. Send the command /newbot.
STEP 2
Name it & get a token
Follow the prompts (pick a display name and a unique username ending in "bot"). BotFather replies with a token that looks like 123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx. Copy it.
STEP 3
Add it to your channel
Open your Telegram channel → Administrators → Add Admin → search for your bot's username → give it permission to post messages.
Finding your channel ID If your channel has a public username, it's simply @yourchannelname. If it's private, forward any message from the channel to @userinfobot to get its numeric ID (looks like -1001234567890).

3Connect it to your site's code

In your GitHub repository:

  1. Go to Settings → Secrets and variables → Actions
  2. Click New repository secret, name it TELEGRAM_BOT_TOKEN, paste your bot token
  3. Repeat for TELEGRAM_CHANNEL_ID, using your channel's @username or numeric ID
That's it — it's now live. The workflow file .github/workflows/telegram-daily-post.yml already runs scripts/telegram-post.mjs every day at 15:00 UTC. Edit the cron line in that file to change the time.

4Test it before going live

Preview exactly what will be posted today, with no bot token needed and nothing actually sent:

node scripts/telegram-post.mjs --dry-run

Once your secrets are set, you can also trigger a real post immediately (don't wait for the daily schedule) from GitHub: Actions tab → "Telegram daily tool post" → Run workflow.

6Troubleshooting

ProblemFix
Nothing posted, workflow shows red ✕Check both secrets are spelled exactly right, and the bot is an admin of the channel (not just a member)
"chat not found" errorYour channel ID is wrong — re-check the @userinfobot trick above
Post looks wrong / cut offEdit the text template inside scripts/telegram-post.mjs
Want a different timeEdit the cron line in the workflow file — cron times are UTC
