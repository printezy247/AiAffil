Exchanges, Brokers & Trading Bots

Feature 5 of 13 — a comparison table page for crypto exchanges and trading bots.

Live at deployment Uses shared click tracking No setup required

1What this does

A new page at /brokers lists crypto exchanges (Binance, Bybit, OKX, Coinbase), trading bots (3Commas, Cryptohopper, Pionex), and charting tools (TradingView) in comparison tables grouped by category — fees, "best for," and a Visit button per row. It's linked in the site nav as "Exchanges & Bots" and included in the sitemap automatically.

2Nothing to configure — but one thing to do before promoting it

These links currently point at each platform's homepage, not an affiliate link Exactly like the main tool catalog (see the main README's "Get your own affiliate links" section): join each exchange/bot's affiliate or referral program, then update the url field for that entry.

3Where to edit it

All content lives in one file — no code knowledge needed to update it:

FilePurpose
data/brokers.jsonEvery row on the page — name, URL, fees, category, description
app/brokers/page.tsxThe page layout, if you want to change the design

To edit an entry: open data/brokers.json, find the platform by "slug", and change its "url", "feeHighlight", or any other field. To add a new platform, copy an existing block and adjust the values — "category" controls which table section it appears under (a new category name automatically creates a new table).

4How clicks are tracked

Every "Visit" button routes through /go/[slug] — the same click-tracked redirect the tool catalog uses (see the Feature 1 setup guide). No extra setup needed; it already works because /go checks both data/products.json and data/brokers.json.

5Troubleshooting

ProblemFix
New broker doesn't show upCheck the JSON is valid (no trailing comma, matching quotes) — a broken file will fail the site's build
Visit button 404sThe slug field must be unique across both products.json and brokers.json
